# FMPO Flashcards — Faculté de Médecine et de Pharmacie d'Oujda

App de flashcards de révision pour le programme Internat / Résidanat d'Oujda (2013).

- **409 sujets · 11 936 flashcards** (toutes extraites des 6 PDFs du programme)
- 6 disciplines : Anatomie (60), Biologie (61), Pathologie médicale (114),
  Pathologie chirurgicale (66), Urgences médicales (55), Urgences chirurgicales (53)
- Plan de révision 32 semaines, classement, niveaux, parrainage 15 DH
- Un seul palier Pro : **100 DH à vie** (toutes les cartes)
- Comptes démo : 5 premières cartes par sujet

Site : https://fmpo-flashcards.github.io/

Voir `DEPLOY.md` pour la mise en ligne (Firebase + GitHub Pages) et la régénération du contenu.
Les sources (PDFs, scripts de build) sont dans `hidden_files/sources/` et ne sont pas déployées.
